## Email Section Definitions

This document defines the building blocks of email designs. Use these definitions to understand what each section type is and create original compositions.

### Header

Brand identification. Centered logo, optional navigation. Present in every email.

### Hero

First visual anchor. Grabs attention and sets the email's tone. The single most impactful visual region.

### Bridge

Transitional element between major sections. Provides breathing room and context shift.

### Product

Showcase one or more products/items with details (image, title, description, optional price/CTA).

### Photo-gallery

Image-forward section for visual storytelling. Multiple images in grid or masonry arrangement.

### Testimonial

Social proof. Quote text with attribution (name, title/company, optional photo).

### CTA

Standalone conversion block. Heading, optional supporting text, prominent CTA button.

### Footer

Brand info, legal compliance, secondary navigation, unsubscribe link. Present in every email.
