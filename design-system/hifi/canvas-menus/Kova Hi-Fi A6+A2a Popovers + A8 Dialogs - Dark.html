  • One component, three behaviors. The shell (head + body + foot) is identical; what varies is the icon-circle color, primary-button class (.danger vs .primary), and whether the body includes a typed-confirm field.
  • Typed-confirm string differs by surface. A4 Delete-brand uses the brand name (here: "Nike"); A9.1 Delete-account uses the literal "DELETE" — locked decision so both feel like the same component but each is hard to fat-finger.
  • The destructive button uses --warn tokens (#e87a4a in dark mode), matching the danger-zone CTA in A7.5 and the failed-invoice tag in A7.2. One semantic, one color.
  • Field with .ok active state on the input shows the moment the typed string matches: border lifts to --warn and a soft warn glow appears. The destructive CTA flips from disabled to enabled at the same moment.
