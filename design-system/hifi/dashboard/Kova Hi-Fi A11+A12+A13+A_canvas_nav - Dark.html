A13 · Network indicator

Online · Offline

Two states. Online is intentionally quiet — a green dotted "Online" pill in the topbar actions cluster (the same one already shown across A7, A12, and dashboard). Offline raises the volume just enough to be unmistakable: a warn pill in the sidebar footer (next to the avatar) so peripheral vision catches it, plus a thin warn banner at the top of the topbar so any new action hits a visible reason for failure. Placement decision: sidebar footer (primary) + topbar banner (secondary). Document this choice in delivery notes.

A_canvas_nav · annotation only — refers to existing 04 Canvas Editor

Canvas navigation back to dashboard

Inside a canvas, there is no brand-switcher (per locked decision). Two affordances bring the user back to the dashboard: (1) the breadcrumb "← {Brand}" click destination, (2) a "Back to dashboard" item inserted as the top entry in the existing logo dropdown. This section annotates both — it does not redraw 04. The mocks below mirror 04's chrome at low fidelity for pin placement only.

Coherence notes — what this file commits to

What survives Batch B

New layout-only classes

  • .empty-grid · .empty-card — review-page catalog only; not shipped to product.
  • .cs-pane · .cs-tabs — Coming-soon shell. Reused identically across Calendar / Swipes / Templates.
  • .net-strip · .offline-banner — A13 indicator placements. Both built on existing warn tokens.
  • .empty-pane already existed (A7); this file just consumes it 8 ways.

Tokens used (none new)

  • Surface: --bg · --page · --rail · --fill
  • Ink: --ink · --ink-2 · --ink-3
  • Lines: --line · --line-2
  • State (offline only): --warn · --warn-soft · --warn-edge
  • State (online + roadmap checks): --ok
  • Accent (AI only): used once on tone-snippets "Draft via interview" and once on "Start with AI".

A13 placement decision (for delivery notes)

  • Primary signal: sidebar footer .net-strip warn pill, always visible while working.
  • Secondary signal: topbar .offline-banner, explains consequences ("changes saved locally").
  • Tertiary signal: the existing topbar online/offline pill swaps from .pill.ok → .pill.warn.
  • Online state shows only the topbar pill (quiet). Sidebar + banner stay silent.

Out of scope

  • Phase-2 tab strip on Templates (My templates / Kova templates) is decorative — both tabs land on the same coming-soon body.
  • Layer-panel empty (A11.2) is shared with Batch B; do not redesign there.
  • A_canvas_nav does not redesign 04. It documents two single-line additions — a click destination on the breadcrumb, and one item inserted into an existing dropdown.
