  • Chrome unchanged from wireframe. Left-rail file-browser shell with the brand switcher — scoped to dashboard / library / settings per the wireframe's aesthetic rules. Canvas and preview get different chrome.
  • Composer leads, quietly. Centered greeting and a single neutral input framed by a soft light surface. No gradient, no AI mark, no mode toggle — the affordance is the box and the placeholder. "Generate on canvas" is the only primary CTA.

What changed from wireframe v5

Polish notes

Everything below is a tightening, not a redesign. Layout, color roles, and information architecture are preserved exactly.

Greeting
Centered, single-line "Good morning, Jiho" at 34px/400 with tight tracking. No subtitle, no glyph, no sync pills — the hero moment is space and a name, not status. Pure focus on the composer below.
Composer
Stripped to essentials: single rounded input on white, "How can I help you today?" placeholder, one "+" attach control, one "Generate on canvas" CTA. Gradient surface, AI glyph, mode toggle, and context pills all removed. Max-width 760px, centered.
Preset chips
Campaign-type labels rewritten in plain English (Promote a sale · Showcase a product · Teach customers · Share reviews · Build community) and styled as neutral pills. Centered under the composer as entry-points, not taxonomy.
Typography
Inter throughout with negative tracking on display sizes. Mono reserved for IDs, timestamps, counts, kbd shortcuts. Body at 13px for UI, 14–15px for hero prose.
Icons
Lucide throughout at 13–15px with ~0.75 opacity for inactive nav, 1.0 for active and primary actions. Replaces the wireframe's text glyphs without adding visual noise.
File cards
Thumbnails use block-level email abstractions: single-email frame, 3-step flow, A/B split. Status tags + frame counts added. Hover lifts subtly. Two rows × four cards replaces the Up next calendar block — dashboard is now canvas-focused.
