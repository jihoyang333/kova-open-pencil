Toasts + Missing fonts pill · B15.1 – B15.5

Four toast variants (success / info / progress / error) extending the Round 1 B1 toast pattern, plus the missing-fonts pill anchored in the top-bar. All toasts lift the canonical .toast shell from B1 byte-for-byte; per-variant differences are icon glyph + ink only. Success icon uses var(--accent) (no green per design.md §5 ban 12); error icon uses var(--warn) (canonical, degrades neutral until status palette ships). Missing-fonts pill uses .pill.warn (canonical) anchored top-bar right, between the file-name region and the avatar.
