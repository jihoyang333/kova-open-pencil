  • Three sizes, one component family. Same .empty-pane base + modifier classes (.inline, default, .full-page). Each scale picks its icon, headline weight, padding, and CTA shape from a fixed table — no per-surface invention.
  • Icon vocabulary differs by concept. Inline = search-x always (filter returned nothing). Panel = data-type icon (brain, quote, etc.) per A11. Full-page = surface icon (the panel as a whole is empty) per A11.1 / A11.7.
  • Shared chrome rules. All three live on --page backgrounds, use --ink-3 for icon glyph + sub-copy, use --ink for headline, and use --accent for any link-style CTA. The size variants only adjust dimension, weight, and padding — never tokens.

What B9 commits to

Lifted + new classes

  • .empty-pane + .empty-pane .ic-wrap + .empty-pane h5 + .empty-pane p + .empty-pane .cta-row — LIFTED VERBATIM from batch-a/dark/Kova Hi-Fi A11+A12+A13+A_canvas_nav - Dark.html. Diff vs source: ZERO.
  • .empty-pane.inline — NEW extension class. Smaller variant for in-list zero-results. Layered BELOW the lifted base block (no modification of the base). Flagged in delivery notes.
  • .empty-pane.inline.viewer-quiet — NEW sub-modifier for the right-viewer placeholder in B9.3 (slightly more padding because it has no CTA).
  • .empty-pane.full-page — NEW extension class for the 48-px full-page reference variant in B9.4. Demonstrates the family's upper-bound size; not a new shipped state (A11.1 / A11.7 already cover this in-situ).
  • .scene-grid · .scene-card — review-page catalog only for B9.4; not shipped.

Tokens used (none new)

  • Surface: --bg · --page · --rail · --fill
  • Ink: --ink · --ink-2 · --ink-3
  • Lines: --line · --line-2
  • Accent (ghost CTA only): --accent

Behavior commitments

  • Search bar stays visible on zero results. Hiding it would force the user to leave the surface to recover.
  • The typed query is echoed in the headline in quotes so the user can re-read what they searched. Implementation reads the live input value into a <span class="q">.
  • Icon glyph for B9 is always search-x. Different from A11.x (data-type icon) — distinguishes "filter returned nothing" from "no data exists yet". A11.8 generic-no-data uses search-x already; B9 inline reuses the same glyph at smaller scale.
  • Ghost CTAs use --accent ink with no chrome (no border, no fill). Hover background lifts to --line-2. Same treatment as B1.x toast inline action buttons.
  • No primary .btn in the inline empty pane — the user already has the search input + segmented filter. Adding a primary CTA would compete with those existing affordances.
  • Search scope = active tab/filter only. KB sources search filters the active tab (Knowledge base / Past emails / Products); switching tabs clears the search. Documented for the implementer.

Scope split with A11

  • A11.x = "no data exists yet." Use the data-type icon (brain, quote, bookmark, book-open, store). Headline introduces the concept; CTA invites creation.
  • B9.x = "data exists but doesn't match this filter." Use search-x always. Headline echoes the query; CTA clears the filter or points at a smarter alternative.
  • The two surfaces never render simultaneously. If the user has zero memories, A11.3 takes the surface — search isn't possible. If the user has memories but searches for something not in them, B9.1 takes the surface.
  • If the founder wants both icon styles unified (always search-x for any zero-result regardless of cause), the change is a single class swap on each A11.x scene. Flagged as a deliberate split — defaulting to differentiated icons because the user's expected next action differs (create vs clear filter).
