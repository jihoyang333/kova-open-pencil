New layout-only classes (flagged)

  • .char-counter + .char-counter.warn — small caption bottom-right of textarea. Inkpath: --ink-3 idle → --warn at >90% cap.
  • .delete-ghost — destructive ghost-link in the foot-left meta region. --ink-3 idle → --warn on hover. No chrome.
  • .btn.danger — re-declared with token-only colors. Default state matches .btn.primary exactly (light --ink fill + dark --page text) per status-palette deferral (design.md §5 ban 12). Destructive semantic is carried by copy + upstream ghost-link, not chrome color. Swaps to warn-color background once the status palette ships — no markup change.
  • .state-cap — review-page only; small banner above each in-flow dialog. Not shipped to product.
  • .acc-frame.dim — review-page only; backdrop dim extension on the lifted .acc-frame. Not shipped to product.

Tokens used (none new)

  • Surface: --bg · --page · --rail · --fill · --fill-2
  • Ink: --ink · --ink-2 · --ink-3
  • Lines: --line · --line-2
  • Accent (focus + selected row): --accent · --accent-soft
  • Warn (delete affordances + char-counter near-cap): --warn

Behavior commitments

  • Required fields — Save disabled until both populated. Edit Save also disabled until dirty (a value actually changed).
  • Char cap — hard block at the cap value (60 for Label, 500 for snippet content, 1000 for block content). No truncation, no destructive trim.
  • Submit / cancel — Esc cancels. Cmd/Ctrl+Enter submits when valid. Enter in Label submits; Enter in Content inserts a newline.
  • Delete flow — Edit modal's Delete ghost-link → B3.5 confirm → on confirm, both modals close + B1.4 Undo toast fires (5s).
  • Type segmented (B3.3 only) — defaults to Text on Add. Persists across Edit. Changing it doesn't migrate the block's drag-drop history; it only affects future drag scope.
