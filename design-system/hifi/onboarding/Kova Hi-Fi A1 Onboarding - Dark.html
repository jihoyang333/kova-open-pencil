A1 · Pattern locks for downstream files

What this file establishes

A3 New-brand flow (file 4) inherits all of this verbatim — same progress strip, same card, same connect surface, same brand-kit drop+AI surface. Only the step-1 (auth) screen is omitted.

Progress strip
Wordmark · 5 dot segments · "Step N / 5" mono. Top of frame, full bleed under a 1px line. Active dot is wider; completed are --ink-3; upcoming are --line-2.
Onboarding card
480px (560 for brand-kit only). Eyebrow mono · 26px H1 · 14px lede · field stack · ghost+primary action row. Centered in stage.
Affixed input
Mono https:// prefix rail + free-text middle + optional mono suffix (.myshopify.com). Reuse for any structured URL field across the app.
OTP cells
6 cells, 44×52, mono 18px. Cursor cell uses the input focus ring. Empty cells dim to --ink-3. Reuse for A15 light-mode auth OTP.
Connect surface
Card with logo glyph + name/sub + status pill, body shows scope list with check/cross icons. Reuse for A10 reconnect modal and Account → Integrations cards.
AI extraction surface
Accent-soft bg, accent-2 border, accent-ink text. "AI" mono pill. Check/circle-dashed list with mono meta. The accent is locked to inference surfaces — never decoration.
