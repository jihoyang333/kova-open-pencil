.bp-shell + .bp-top
Sidebar-less chrome for between-brands routes. 56px top with wordmark left + avatar pill right. Reuse for any post-login route that's not yet committed to a brand.

Brand card — logo glyph + name/url + status pills + 2-cell meta footer. Kebab is the launchpad for A4 rename/archive/delete modals.
A3 progress strip
A1's strip + a "context" hairline-divider segment ("New brand · {name}") + a "Cancel" close button on the right. Reuse pattern for any sub-flow launched mid-app.

5 tints (coral / sage / sand / violet / graphite) sampled from favicon. Same set used by sidebar brand-switch and breadcrumb crumb-brand for visual continuity across brands.
