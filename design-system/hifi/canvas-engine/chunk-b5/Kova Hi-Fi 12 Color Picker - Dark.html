12 · Color picker popover

Reusable color picker invoked from page background, fill rows, gradient stops, stroke color, and effect color. Multi-mode (Solid / Linear gradient / Radial gradient / Image) when the host context is a Fill section; "Color" header only for the four single-mode contexts. Inter throughout, single accent (#3b82f6), 1px hairlines, locked tokens. Picker INTERIOR is designer territory; canvas chrome is lifted byte-for-byte from Kova Canvas - Final.html.

14 scenes · 1440 design width · dark · inherits kova-hifi.css
B14 · color picker · solid mode

12.1 — Solid mode (default)

Picker invoked from a Fill row. Four mode tabs (Solid / Linear / Radial / Image) at top, saturation/value canvas with current hue, hue slider, alpha slider, hex input + mode toggle + eyedropper trigger, and three swatch rows (Recent / Brand / On this page).
