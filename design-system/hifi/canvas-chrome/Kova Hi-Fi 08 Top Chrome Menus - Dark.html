All eleven popovers above share one component shell. Locking it here so B3.4 (page right-click), B4.8 (layer right-click), B5.7 (asset right-click), B7.1 (inspector overflow •••), B10 (canvas right-click), and B2 (tool dropdowns) inherit byte-identical chrome.

  • Tokens — surfaces. Background --rail; border 1px --line; radius 8px; padding 4px (outer); shadow 0 24px 60px rgba(0,0,0,0.55), 0 1px 0 rgba(255,255,255,0.03).
  • Item row. Height 26px; horizontal padding 10px left / 8px right; gap 10px; radius 5px; cursor pointer. Hover background --line-2; opened-submenu state background --fill.
  • Label. 12.5px Inter 450; --ink. Flush-left.
  • Submenu chevron. 12px Lucide chevron-right; --ink-3; flush-right with 8px outer pad.
  • kbd glyph row. Right-aligned. Inter 11px tabular-nums; --ink-3 default, --ink-2 on hover. macOS glyph order: ⌃ → ⌥ → ⇧ → ⌘ → letter. Each glyph in its own <kbd>; no boxes around individual chips.
  • Toggle row. 18px gutter on left for 12px Lucide check glyph; opacity:0 when off, 1 when checked. .checkable reduces left padding to 6px to keep optical alignment with non-toggle rows.
  • Separator. 1px --line-2; 4px vertical margin / 4px horizontal margin (pulls away from item radius).
  • Section group label. 9.5px Inter 500 sentence-case; --ink-3; padding 8/10/4/10. Used in Arrange (Pack / Distribute spacing / Distribute edges) and Boolean ops (Multi-select only).
  • Disabled. Color --ink-3; cursor default; no hover bg. Phase 2 chip = 9.5px Inter, --fill bg, 1px/5px pad, 3px radius — pinned right.
  • Destructive. Color --warn (label + kbd row); hover bg --warn-soft. Used for "Move to trash" / "Delete" — opens A8.4 useConfirm.
  • Min-widths. w-260 (root menus, simple submenus). w-280 (Edit / Object / View / Arrange / Text — anything with longer rows or kbd-row crowding). Never less than 220px.
  • Sub-popover offset. 22px right of parent menu's right edge; top edge aligned 4px below the parent row's top. Same offset for every sub-of-sub.
