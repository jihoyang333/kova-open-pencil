Coherence notes

Patterns this file inherits, decisions that need wiring, and links to sibling surfaces.

Coherence audit
A15 · notes
  • Theme isolation. This file does NOT set data-theme="dark". It uses design-system/kova-hifi-light.css tokens. Zero dark-mode leakage — verified by inspection. The exception is A9.3 Account-pending-deletion, which is a DARK route per founder direction (lives in batch-a/dark/).
  • Card geometry. 380px standard, 420px for the OTP screen only. 10px radius, 1px --line border, soft shadow 0 14px 40px -24px rgba(0,0,0,0.10). Padding 28px / 28px / 24px.
  • Inputs. 9/12 padding, 14px Inter, 1px --line border, 6px radius. Focus ring is rgba(17,17,17,0.06) — same opacity as A1 Onboarding's focus state, recolored for light. Placeholder is --ink-3.
  • OTP cells. 44×52px exactly — match A1 Onboarding 01.b.ii cells dimension-for-dimension. Inter 18px / 500. Cursor is a 1px ink caret.
  • CTA buttons. Reuse .btn.primary from kova-hifi-light.css (ink bg, white text). Full-width via .auth-cta. Secondary uses base .btn + .auth-second for full-width.
  • Mono usage. Banned on chrome per design.md §5 ban 1. All chrome typography is Inter; tabular numerals via font-feature-settings: "tnum".
  • AI accent NOT used. Auth is not generative; AI-blue stays reserved for Onboarding step 5, A6 ⌘K AI chat, and A7 Identity "Draft via interview".
  • Routing notes for engineering. Screens 01 + 02 share a route; 03 is the same route in "sent" state. 04 is reached via the secondary CTA on 01/02/03. 05 is its own route. 06 is the magic-link callback handler.
  • Open wiring questions (flag in BATCH_A_DELIVERY_NOTES.md): (a) auto-submit OTP on 6th digit? (b) "Keep me signed in" default — pre-toggled on as drawn, or off? (c) does Forgot-password actually exist in MVP, or hide the entry until email+password upgrade ships?
