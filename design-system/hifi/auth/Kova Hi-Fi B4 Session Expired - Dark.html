B4.7 · Your session expired

User's Supabase session expires while they're inside the app — could be a 24-hour expiry, an admin-revoked token, or a server-side logout from a different device. Page replaces app chrome with a centered card on the dark plate. No sidebar, no topbar — auth state is lost, so app chrome is also gone. Primary CTA returns to the light /login route; secondary "Go to dashboard" is disabled because the user is no longer signed in to one.

  • Same B2 chrome — clock glyph instead of compass. Card geometry, padding (40/32), icon-tile invisibility, and CTA-stack max-width 280px are byte-identical to B2.1. Visual continuity tells the user "this is the same product showing me a different state," not "I clicked a link and ended up somewhere else."
  • Disabled secondary tells the user they can't navigate. "Go to dashboard" is shown but greyed because the user just lost the session that lets them in. Pre-empting the click prevents a broken-feeling 401 round-trip. Once Sign-in succeeds, the dashboard is one click away.
  • Sign-in routes to the light /login surface (the canonical auth chrome from A15). The dark session-expired page is a one-shot bridge — users don't stay here.
  • Local Yjs autosave is the load-bearing claim in the sub-copy. "Your work is saved" is true because canvas state persists locally regardless of session — re-mention so users don't worry about losing edits while signed out.
