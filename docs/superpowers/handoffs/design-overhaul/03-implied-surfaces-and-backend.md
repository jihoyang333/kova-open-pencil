## 1. Summary

> **Tech-stack note (read first).** Kova is a fork of OpenPencil. The architectural picture: same data model surface as Figma (Figma plugin API compatible via `figma-api-proxy.ts`); same file format (Kiwi binary, reads `.fig` natively); same layout engine (Yoga WASM); **different renderer** (CanvasKit/Skia WASM vs Figma's custom WebGPU+C++ — visual quality identical, performance ceiling lower at 10k+ nodes which is irrelevant for email-design scale of ~50–300 nodes); **different multiplayer** (Yjs CRDT; Trystero P2P + awareness code dormant in MVP per Q6 vs Figma's custom OT central server). Scene graph covers 16 of Figma's ~30 SceneNode types — out-of-scope Figma types (STICKY, TABLE, CODE_BLOCK, MEDIA, WIDGET, STAMP) not needed for email design. **Kova MVP is single-user per canvas (Q6)** — Yjs document CRDT + y-indexeddb stay live for offline-first solo persistence; Trystero P2P + awareness code remains dormant in `packages/core/` for Phase 2+ revisit. See companion `q1-5-answers-03-implied-surfaces-and-backend.md` for full architectural verification (six load-bearing decisions verified against `packages/core/src/scene-graph.ts` 2026-04-25).

### Top 3 highest-impact net-new backend pieces

1. **Foundational primitives split across four execution categories (powers ~30 KEEP-new rows)** — Per Q4 verification, the original "canvas-extension scaffolding for ~15 features" plan is fundamentally miscategorized. The features split into:
   - **Core modifications (~6)** — Slice node-type (Q1), **Measurement node-type (Q11)**, aspectRatio, page-level export flag, page-bg-visibility, scale tool, OpenType wiring, per-text-run attrs (bullets, links). Lift the `packages/core/` lock per CLAUDE.md amendment.
   - **Renderer-only changes (~1 net)** — Mask compositing for existing `isMask` + `maskType` fields (Q2 verified data model already in core, only renderer work in `renderer/scene.ts` sibling traversal). Effects renderer already shipped (Q3 #12 verified — `renderer/effects.ts` uses Skia ImageFilter for all 5 effect types — zero work needed). NEW: `renderer/measurements.ts` for `MEASUREMENT` NodeType (Q11) — dashed lines + auto-distance label + selection handles.
   - **App-level inspector wiring (~7)** — Vertical text alignment, stroke alignment, multiple fills, image fill picker (4 modes per Q21), gradient editor UI, **Effects inspector (5 types)**, **Boolean ops menu (Q3 #14)**. All engine-ready per Q3.
   - **App-level overlays (~6)** — Frame/Mask/Slice/Snap/Layout-guide/Pixel-grid overlays, Hover contour, Find highlight, Eyedropper crosshair, Measurement annotations renderer.
2. **Snapshot / version-history store (powers 2 explicit rows + impacts trust UX broadly) — RESOLVED per Q7 (Figma-exact)** — `canvas_snapshots` table + Storage bucket `canvas-snapshots` + 3 RPCs + autosnapshot heartbeat composable + 30-day cron. Yjs doc bytes (Kiwi+Zstd ~10× compression), per-canvas, 30-day free / unlimited paid retention, 30-min + on-disconnect + on-tab-close + on `⌥⌘S` cadence.
3. **Account page + Stripe + GDPR cascade (powers §2.14 + ~5 cross-cuts) — RESOLVED per Q12–Q15** — Full-page route `/account` with sidebar sections (Profile, Plan & Billing, Brand Kit, Integrations, Danger zone). User-level scope (Stripe customer one-per-user — freelance marketers pay one subscription for many brands). Build Stripe foundation now (Checkout + Customer Portal + webhooks per Stripe SaaS guide). GDPR Art. 17 + Art. 19 cascade orchestrator: 30-day soft-delete + daily hard-delete cron across Stripe + Shopify + Anthropic + Supabase Storage + DB. Launch strategy + pricing intentionally out of scope for this doc.
4. **User-preferences persistence layer (powers ~8 scattered rows)** — Per Q5: two-layer architecture — `users.preferences` JSONB column (cross-device sync — better than Figma's local-only model) + localStorage for per-device UI minutiae (sidebar widths, panel collapse, recent colors). Backs Accessibility settings, collapse states, recent colors, view-toggle persistence, default-on snap toggles (DEFERRED but the storage layer should be ready).

All 3 maskTypes ship in MVP per Q2. Affects 6+ rows.

6. **Snapshot/version-history store (Q7 Figma-exact)** — Yjs doc bytes (Kiwi+Zstd) + `canvas_snapshots` table + Storage bucket + 3 RPCs + autosnapshot heartbeat composable + 30-day cron. Underlies all "user can recover" trust UX.
7. **Account page + Stripe + GDPR cascade (Q12+Q13+Q14+Q15)** — Full-page route `/account` + sidebar sections + `users` Stripe columns + Edge Functions (`stripe-webhook`, `stripe-checkout-session`, `stripe-portal-session`) + `users.deleted_at` + `account-deletion-request` + `delete-account-cron` (cascades Stripe + Shopify + Anthropic + Storage + DB). User-level scope.
8. **Boolean operations menu wiring (Union/Subtract/Intersect/Exclude)** — Q3 #14 verified `figma-api.ts` exposes `figma.booleanOperation()`, `tools/vector.ts` wires all 4 ops. Engine ready — **only Object-menu + right-click wiring**. Free Figma-parity win.
9. **Right-click context menu shell + `useObjectActions()` composable (Q18)** — used by 4 surfaces (Pages, Layers, Canvas, Assets). Build once, share across all. Powers both inspector overflow `•••` (compact subset) and canvas right-click (full set).
