# Wave Audit Prompts

**Status:** active. Created 2026-05-21.
**Purpose:** Self-contained audit handoffs. After a wave's execution agent ships its DONE report, a fresh Claude Code agent runs the wave's audit prompt and verifies the work end-to-end before the wave is allowed to merge to `feat/m9-shopify`.
**Audience:** Jiho (founder) — paste the audit prompt verbatim into a fresh session. The audit agent does the rest.

---

## Workflow

1. Wave's execution agent prints "DONE" + writes `cluster-reports/<wave>-cluster-NN-DONE.md`.
2. Founder spawns fresh Claude Code session (Opus 4.7) at `/Users/jihoyang/kova-main/kova-open-pencil-1`.
3. Founder pastes the matching wave audit prompt verbatim.
4. Audit agent reads PRD + Plan + DONE report + IMPLEMENTATION_PROMPT + DESIGN-SYSTEM-COMPLIANCE-RIDER + MASTER-EXECUTION-GUIDE + the original execution prompt (full scope) + the branch diff.
5. Audit agent runs `superpowers:code-reviewer` + cluster-appropriate subagents (`security-auditor`, `database-reviewer`, `e2e-runner`, `typescript-pro`).
6. Audit agent writes verdict to `wave-audits/reports/<wave>-cluster-NN-AUDIT-REPORT.md`.
7. Founder reads verdict. PASS → merge. PASS WITH WARNINGS → review warnings, decide. BLOCK → return to execution agent with the report as a fix list.

## What an audit prompt checks (every wave)

| Dimension | What |
|---|---|
| **Plan task completion** | Every Plan §6 task has a one-per-task commit on branch. Cross-reference DONE report. Surface silent omissions. |
| **Scope discipline** | No out-of-scope files touched. `packages/core/` lock honored (except where lift-the-lock policy + CHANGELOG-KOVA.md grants exception). No invented features. |
| **Quality gates (re-run)** | `bun run build` / `bun run check` / `bun run test:unit` / `bun run test:dupes` — all green. Audit agent re-runs locally, does NOT trust the DONE report. |
| **Design-system compliance** | `KOVA_AUDIT.md` + `tokens-used.md` exist in `cluster-audits/`. No inline hex / inline px / `<style>` blocks / raw SVG / Math.random / `: any` / non-null `!` in changed code. Reka primitives + KovaIcon + Cluster 11 primitives consumed correctly. |
| **Visual fidelity (UI clusters)** | 3-screenshot PR artifact per surface (mockup / impl / diff) under `tests/snapshots/cluster-NN/`. Visual-diff thresholds (0.1% component / 0.5% screen) verified. Per-screen written diff under `tests/snapshots/cluster-NN/<surface>-diff.md`. |
| **TDD discipline** | Test commits precede or accompany impl commits (RED → GREEN → REFACTOR). Tests exercise behavior, not implementation. |
| **Code review** | `superpowers:code-reviewer` agent — PASS. Readability, correctness, immutability (per `~/.claude/rules/common/coding-style.md`), file/function size limits. |
| **Security** | `security-auditor` agent for auth/payment/secrets clusters. No `SUPABASE_SERVICE_ROLE_KEY` / `ANTHROPIC_API_KEY` / `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` exposed to browser. RLS verified. Parameterized SQL. CSRF + rate limiting. |
| **Commit hygiene** | Conventional commits. One commit per Plan task. No squashes. No `--no-verify`. |
| **Done-report accuracy** | Random sample of DONE-report claims verified against actual code/tests. |
| **Deferred items** | Every deferred item tracked in `CHANGELOG-KOVA.md` with reason + upstream-PR status. No silent scope cuts. |
| **Cross-cluster contracts** | W3/W4 closures honored (e.g. `C-LOW07a.3` `FORMAT_VERSION` lockstep, `C-LOW09.11` migration registry, Wave-0 contracts in dependent clusters). |
| **Founder-locked constraints** | All PRD founder locks respected. No silent re-litigation. |

## Verdict format

Every audit report ends with one of:

- **✅ PASS** — clear for merge. Optionally include up to 5 LOW-severity observations as "next-wave watchlist".
- **⚠️ PASS WITH WARNINGS** — non-blocking. CRITICAL + HIGH = 0; MEDIUM ≤ 3. Founder reads warnings, decides. Merge generally OK.
- **🛑 BLOCK** — at least 1 CRITICAL or 2+ HIGH findings. Must fix before merge.

Findings are categorized:

- **CRITICAL** — security flaw, data loss risk, broken cross-cluster contract, scope violation that breaks downstream waves.
- **HIGH** — design-system rule violation, missing Plan task, missing visual-diff artifact, code-review hard-fail.
- **MEDIUM** — readability / maintainability / inconsistency, recoverable test gap, doc drift.
- **LOW** — style nit, micro-optimization, comment-quality suggestion.

## Notes

- Audit prompts are **read-only** by default. The audit agent MUST NOT push code, modify branches, or amend commits. It only investigates + reports.
- If the audit agent finds a CRITICAL issue mid-investigation, it should stop and surface immediately via `AskUserQuestion` before finishing the rest of the audit.
- Audit agents should burn 30-90 minutes per wave. Faster than execution. Token spend: $40-120 per audit.
- Re-running the same audit prompt is idempotent — the agent overwrites the report under `reports/`.
